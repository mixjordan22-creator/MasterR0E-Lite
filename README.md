# MasterR0E Lite

Una interfaz ligera y moderna inspirada en One UI Lite, diseñada para teléfonos Android de gama baja y media.

## Objetivo
- Mejorar la fluidez visual
- Mantener bajos recursos del sistema
- Ofrecer una apariencia premium y personalizable
- Adaptarse a pantallas pequeñas y resoluciones bajas

## Características
- Tema oscuro moderno
- Iconos grandes y legibles
- Panel de acceso rápido
- Diseño minimalista y limpio
- Optimizado para dispositivos de gama baja

## Ejecutar
```bash
flutter pub get
flutter run
```

## Estructura base
- `lib/main.dart` — pantalla principal y componentes visuales
- `lib/theme` — personalización futura del tema
- `lib/screens` — pantallas adicionales
- `lib/widgets` — componentes reutilizables
